## Findings and decision

The shared `assets/js/shared/vm-topbar.js` already mirrors primary desktop links into the
narrow-screen overflow navigation, manages the existing menu disclosure, and injects shared
theme/Clipboard behavior. `assets/css/topbar.css` owns the common desktop and mobile chrome.
Use runtime injection for the new Tools disclosure rather than duplicating authored markup in
every route.

At desktop widths, insert Tools immediately after the existing Apocrypha primary link. It is a
button-controlled disclosure containing Color Pie and Deck Explorer links. Both external anchors
must use `target="_blank"`, `rel="noopener noreferrer"`, a visible outbound arrow hidden from
assistive technology, and existing `.visually-hidden` text that says they open in a new tab.
Keep the links ordinary anchors; do not add application-menu roles.

The button uses native Enter/Space activation. The controller must synchronize `aria-expanded`,
close on Escape with trigger-focus restoration, and close on outside click or focus leaving the
disclosure. In `syncMenuNav()`, project a labeled Tools group into the existing mobile overflow
after Apocrypha and before the cloned utility Guide link. Existing `.vm-menu-link` semantics and
44px targets apply.

expectation in `scripts/validate-frontend-html.mjs` and the epoch mapping in
`tests/shared/clipboard-tests.js` with those URL-only consumer changes.

`scripts/topbar-browser-smoke.mjs` is the focused browser-owner extension: add a Tools-only
execution path that checks desktop placement/state/focus/Escape/outside-close, exact external
attributes and accessible names, the narrow overflow-group order, and horizontal overflow. Do
not make its existing screenshot or broad viewport matrix a new requirement.

`tests/shared/theme-controller-tests.js` has a historical byte-baseline preservation assertion
that is already stale for earlier Home changes. It is not selected for this task and must not be
silently advanced to bless this candidate.

## Protected contracts and risks

The canonical five authored primary `data-vm-nav` links remain unchanged. Tools is not a sixth
route and must not receive `data-vm-nav` or an `aria-current` state. The HTML validator’s
five-primary-route contract therefore remains intact while gaining shared-component assertions.

Changing shared JS/CSS without coherent cache URLs would allow stale runtime/style combinations;
all canonical consumer references must move together. The injected component must tolerate a
missing topbar/nav by no-op, as the existing runtime does. Preserve existing menu, Guide,
theme, Clipboard, feedback, current-page highlighting, and reduced-motion behavior.

Do not change homepage cards, per-route authored navigation markup, data, generated sources,
the Color Pie or Deck Explorer applications, DNS, hosting, deployment, footer, or external-app
claims.
