# VM-551 Card-Rationale Coverage Gaps

## Classification Rule

Full means approved examples provide genuinely useful coverage and no meaningful unresolved card-rationale coverage defect is adjudicated. Full does not require three cards. Partial means at least one useful approved example exists while a meaningful unresolved coverage defect remains. Gap means no relationship is currently approved for public runtime. Three is only the display maximum, never a quota.
