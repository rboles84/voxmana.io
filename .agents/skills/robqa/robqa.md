# Vox Mana — RobQA navigation

This compatibility guide adds no rules or mandatory reading. Read the full [RobQAPass](../../../docs/qa/RobQAPass.md) through the [RobQA skill](SKILL.md). The pass owns classification, independent execution, proportionate evidence, Owner-Visual, findings-to-invariants and exact-candidate exit evidence.

The [workflow reading model](../../../docs/reference/workflow.md#required-reading-model) routes task context, admission, delivery, specialist triggers and handoff/Git accounting. Governing conflicts return to the owning authority; this guide does not reinterpret it.
