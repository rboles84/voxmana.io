# Vox Mana — RobQA navigation

This compatibility guide adds no independent behavioral rules. Read the full [RobQAPass](../../../docs/qa/RobQAPass.md) through the [RobQA skill](SKILL.md). The pass owns classification, independent execution, proportionate evidence, Owner-Visual, findings-to-invariants, exact-candidate exit evidence, and the [Stateful Adversarial QA](../../../docs/qa/RobQAPass.md#13a-stateful-adversarial-qa) methodology.

The [workflow reading model](../../../docs/reference/workflow.md#required-reading-model) routes task context, admission, delivery, specialist triggers and handoff/Git accounting. Governing conflicts return to the owning authority; this guide does not reinterpret it.
