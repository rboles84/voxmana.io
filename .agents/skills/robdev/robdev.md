# Vox Mana — RobDev navigation

This compatibility guide adds no rules or mandatory reading. Read the full [RobDevPass](../../../docs/dev/RobDevPass.md) through the [RobDev skill](SKILL.md). The pass owns grounding, authority/producer routing, pre-edit contract, implementation, stop conditions and the QA transfer packet.

The [workflow reading model](../../../docs/reference/workflow.md#required-reading-model) routes task context, admission, delivery, specialist triggers and handoff/Git accounting. Governing conflicts return to the owning authority; this guide does not reinterpret it.
