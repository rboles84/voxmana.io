Field Guide // The Implicit Maze

Read the search. Change one thing.

The Maze shows its work.

Use the translation, reading context, and result state to decide what to change next. The search stays in your hands.

I // What did Maze understand?

Read the request beside the query.

In Plain Reading, You wrote preserves your words. Maze translated is the exact Scryfall query that ran. Recognized, ignored, warning, and unresolved rows explain the current translation.

II // What is affecting this search?

Context is visible; filters stay literal.

A reading may keep a return path and associate new Reading Finds without adding hidden filters. A dossier thread can supply the query that opened the Maze. Search independently keeps the current query but does not use the retained reading: new Finds are not attached to that reading, while the reading and its existing Finds remain unchanged. Use Restore reading context or Back to return.

Standalone search

No reading is changing this query.

Reading available

The return path and new Finds association remain; the query is unchanged.

Dossier thread

The query came from the dossier; no extra reading filters are added.

Searching independently

The retained reading and its existing Finds remain unchanged; new Finds are standalone until you restore the reading context.

III // Why did this search miss?

Translation trouble and zero matches are different.

Fix what Maze did not understand before broadening the query. If the translation is sound and the query returns zero cards, change one visible constraint yourself.

Maze did not fully understand Signs

Unresolved terms, an important warning, or an existing ambiguity.

Next action

Rephrase or remove one unresolved element. Use an existing alternative when the inspector offers one.

The query ran; zero cards matched Signs

A valid executable query, no material translation issue, and a zero result.

f:commander mv=99 Next action

Broaden or remove one constraint, then search again. Maze does not guess which constraint caused the miss.

IV // Useful results

Inspect, refine, or carry the thread forward.

Open a card for detail, refine the visible query, set a useful card aside, or open the same query in Scryfall. Reading Finds keeps useful cards together locally. Finds saved with reading context can stay attached to that reading; independent Finds remain standalone. It is not a deckbuilder.
